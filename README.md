# dotnet10-agentframework-foundry-otel-appinsights-mcp-mslearn-apisix_chat
Exemplo em .NET 10 de Console Application que faz uso do Microsoft Agent Framework, com integração com Microsoft Foundry, interação com um servidor MCP - utilizei o Microsoft Learn Docs MCP Server para testes - e monitoramento via OpenTelemetry + AppInsights. Inclui Docker Compose para criação do ambiente de testes com o APISIX como AI Gateway.
